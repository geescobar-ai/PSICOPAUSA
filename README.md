# 🌿 PSICOPAUSA
> **Cuidado para quien cuida**  
> Aplicación web de autocuidado emocional, regulación somática y acompañamiento reflexivo para estudiantes y profesionales de Psicología en formación clínica.

---

## 📱 ¿Cómo probar la aplicación en tu computador o celular?

### En tu computador:
1. Simplemente haz doble clic en el archivo [`index.html`](./index.html) en tu carpeta de proyecto para abrirlo en cualquier navegador (Google Chrome, Microsoft Edge, Firefox o Safari).
2. O ábrelo mediante cualquier servidor local.

### En tu celular:
1. La aplicación cuenta con una barra de navegación táctil inferior optimizada para pantallas táctiles.
2. Una vez publicado el enlace en GitHub Pages, podrás abrir [`https://geescobar-ai.github.io/PSICOPAUSA/`](https://geescobar-ai.github.io/PSICOPAUSA/) directamente desde el navegador de tu celular.

## 🧭 Módulos de la Aplicación

1. **Dashboard & Check-in Emocional:** Registro diario de emociones (hasta 3), nivel de impacto emocional en escala 1-10 con descriptores clínicos cualitativos, detonantes de práctica y notas de descompresión.
2. **Gimnasio de Regulación Emocional:** Ejercicios guiados paso a paso de Grounding 5-4-3-2-1, orbe de respiración interactivo, selector de sonido ambiental y catálogo de protocolos somáticos (Respiración 4-7-8, liberación muscular, defusión de rol y coherencia cardíaca).
3. **Entrenamiento en Límites Profesionales:** Simulador interactivo de dilemas éticos reales (mensajes fuera de horario por WhatsApp, confidencialidad, contratransferencia) con opciones y retroalimentación formativa inmediata.
4. **Diario Privado de Reflexión:** Espacio seguro y confidencial con 3 preguntas guiadas post-consulta, contador de palabras, selector de etiquetas emocionales y botón de marcado para supervisión.
5. **Centro de Ayuda en Crisis (Botón de Emergencia):** Rutas inmediatas de atención telefónica oficial (Línea 106 Territorial Boyacá, Línea 123 de Emergencias, Línea Nacional 192 MinSalud), guía de desescalada en ataques de pánico y directorio asistencial.

## 🔒 Privacidad y Protección de Datos
- **Sin datos de pacientes:** PSICOPAUSA no almacena nombres, historias clínicas ni información identificable de terceros.
- **Almacenamiento Local:** Los registros se guardan en el almacenamiento local (*LocalStorage*) del navegador del practicante. No se transmiten a servidores externos ni supervisiones académicas.
